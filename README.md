# 🌸 Iris Flower Clustering using K-Means and PCA

## 📌 Project Overview

This project performs **Iris Flower Clustering** using the **K-Means clustering algorithm**.

The main objective is to group Iris flowers into **3 clusters** based on their flower measurements. **PCA (Principal Component Analysis)** is also applied to reduce the dataset from 4 dimensions to 2 dimensions for visualization.

This project demonstrates an **Unsupervised Machine Learning** workflow.

---

## 🎯 Objectives

- Apply K-Means clustering on the Iris dataset.
- Use **K = 3** clusters.
- Visualize the generated clusters.
- Apply PCA for dimensionality reduction.
- Compare predicted clusters with the actual Iris labels.
- Evaluate clustering using the **Adjusted Rand Index (ARI)**.

---

## 📊 Dataset

The project uses the **Iris Flower Dataset**.

The dataset contains 150 samples and 4 numerical features.

### Features

| Feature | Description |
|---|---|
| Sepal Length | Length of the sepal |
| Sepal Width | Width of the sepal |
| Petal Length | Length of the petal |
| Petal Width | Width of the petal |

### Classes

The original Iris dataset contains three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica
